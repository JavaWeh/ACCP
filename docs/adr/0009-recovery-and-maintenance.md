# ADR 0009：维护门禁与可验证恢复

状态：实施中。适用于 D03–D10 候选版本，不是正式发布批准。

## 决策

保持模块化单体、PostgreSQL、JetStream 和单机 Compose。PostgreSQL 是恢复依据；消息系统只恢复尚未物化到事件 Feed 的投递，不据历史事件执行外部副作用。

API 写事务和 Worker 执行事务先对 `runtime_state` 持共享锁，再获取项目授权锁。本机维护命令持排他锁，等待已有事务结束；存在已提交但尚未结算的 RUNNING 工具操作时拒绝进入维护。维护期允许已授权读取和原有 UNKNOWN 核对接口，阻止其他写入、自动领取及工具执行。

备份使用 age 接收方公钥加密。定时任务只需公钥；私钥由恢复操作者另行保管。`pg_dump` 与表摘要共享一个导出的数据库快照。包内包含数据库、迁移校验值、不可变镜像标识、公开配置清单、逐表行数及 SHA-256。临时明文只写入工具进程的私有目录，用后清理；容器应将该目录放在临时文件系统。

恢复只接受全新隔离数据库，不删除或覆盖已有数据库。不恢复旧 ACL；完成摘要比对和恢复隔离事务后，才由操作者安装最小权限。失败或中断的恢复保持无运行时权限，使用另一个新数据库重试。

恢复事务撤销所有旧 Session，关闭恢复出的活跃 Run，并把可能在备份后执行的未结工具操作纳入 UNKNOWN 核对。历史快照、成果、终态 Run、审计和已确认副作用账本保持原值。解除恢复门禁前，项目管理员必须完成核对；工具结果必须先经过现有治理接口查询确认，本机工具不能直接编造外部成功或失败。

## 权衡与验证

全表有序摘要增加备份读负载，必须纳入最终容量测试。逐表摘要验证恢复前的原始数据；隔离事务产生的 Session、Run 和操作状态变更另行记录。RPO 按操作者提供的故障时间与数据库快照时间计算；恢复报告的 RTO 是命令运行时间，完整业务恢复还需加入人工核对与重新部署时间。

维护锁属于共享高风险入口变更；权限、幂等、租约 fencing 与唯一活跃 Run 约束保持有效。真实恢复、轮换、故障演练和容量结果分别记录，不以单元测试或脚本存在代替。
