# ADR 0003：持久事件与人类审批

- 状态：接受，待业务实现
- 日期：2026-09-15

## 背景

跨 Agent 任务依赖需要可靠传播；高风险工具调用跨越数据库与外部系统，无法用单个数据库事务保证所有副作用恰好一次。

## 决策

使用 PostgreSQL 事务 Outbox、NATS JetStream、消费者 Inbox 与聚合版本处理至少一次投递。外部调用先保存 ToolInvocation；高风险意图由不同于请求者的人类审核，绑定参数、资源、策略及版本，执行前重新校验。

## 替代方案

直接 Agent 间调用难以恢复和审计；只依赖消息队列的去重无法保护外部副作用；自动把聊天中的“同意”当审批缺少身份和内容绑定，因此不采用。

## 后果与重新评估

需要失败队列、操作核对、UNKNOWN 状态和人工恢复入口。审批可能降低速度，但保留清晰责任。复杂长流程增长到难以维护时再评估工作流引擎，迁移仍需保留操作幂等与审批边界。
