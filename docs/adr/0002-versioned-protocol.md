# ADR 0002：版本化协议、Context 与来源证据

- 状态：接受，待业务实现
- 日期：2026-09-15

## 背景

客户端私有会话结构和记忆不能跨团队可靠共享；需求与 API 在执行中更新时，需要明确执行究竟依据哪个版本。

## 决策

采用 ACCP 自有版本化协作协议、OpenAPI 3.1.1、JSON Schema 2020-12 和 CloudEvents 1.0。Adapter 显式协商能力，ContextVersion 不可变，TaskRun 绑定快照，Artifact 关联运行、输入、不可变外部版本与人类验收。

## 替代方案

共享整段聊天成本高且难以确定权威；始终读取 latest 无法追溯旧执行；把某厂商格式作为核心协议会限制扩展，因此不采用。

## 后果与重新评估

必须维护契约、示例、语义验证与版本迁移。存储快照增加成本，但可按引用关系和保留策略清理正文。若采用外部协作标准，应通过映射 Adapter 和新的 ADR 论证，不直接改变现有领域语义。
