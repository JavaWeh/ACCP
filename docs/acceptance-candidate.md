# D06 / D10 候选版本验收

本轮只生成候选和交接材料，不正式发布、不自动合并、不升级日常环境。四个依赖 PR 为 [运行保障 #12](https://github.com/JavaWeh/ACCP/pull/12)、[协作体验 #13](https://github.com/JavaWeh/ACCP/pull/13)、[Git 来源 #14](https://github.com/JavaWeh/ACCP/pull/14)、[容量与候选交付 #15](https://github.com/JavaWeh/ACCP/pull/15)。

## 功能集验证

- 全量 Linux race 通过，控制面 382.571 秒；事件连续处理、超时后 NAK、延迟重投及工具执行权锁等待的定向 race 23.257 秒通过。
- Go 单元、vet、依赖完整性，Web 类型/构建/格式及浏览器回归通过；交接下载组件覆盖项目诊断与审计导出。
- 契约检查通过：79 个正例、32 个反例、469 处 Schema 编译；工具回归在补入安装包校验后共 14 项通过。
- 提交 `f0e3a1e` 的远程文档/契约、控制面、Web、生产基础和候选构建五组 CI 全部通过。新安装、真实 Keycloak 生命周期与 Git 来源正常路径由生产基础 CI 覆盖。
- 依赖扫描包括 Go 可达调用和两个 npm 锁文件；npm 未发现漏洞，Go 无可达漏洞。模块清单中的 OpenPGP 提示不属于应用导入的可达调用，不将模块提示隐藏成“无任何漏洞信息”。完整历史秘密扫描通过，仅保留管理员手册所述精确 SQL 误报排除。

## 产物与安装实测

[首轮候选构建](https://github.com/JavaWeh/ACCP/actions/runs/35189639266) 完成五个平台原生 Bridge 启动，产物清单为 `v0.5.0-rc.1`，CI 合并提交 `7809195fbb1ec20d1195f8b453c0eb9e91b67b07`，`dirty=false`。下载的 ZIP 摘要为 `c9607ccc8fc863aa38ee8459aab927c47da586acffb748c058e6b39484bf2237`，内部 13 项校验和全部匹配。Go/Web/API/运维镜像 SBOM 分别包含 44/110/37/7405 个组件；API 与 Worker 使用同一镜像。

首包实际升级失败：安装包缺少 Compose 绑定的 `configs/nats.conf`，Docker 将缺失源创建成目录，导致 NATS 无法启动。因此**首包不可交付**，不能以 CI 或摘要通过覆盖部署失败。打包清单已补齐，构建时检查生产与验收 Compose 的全部静态文件挂载；缺文件、误挂目录、相对路径越界与覆盖文件路径解析均有回归。

使用修复后的本地包重新部署，008→009 前向迁移及最小权限通过，退出维护后 doctor 11 项通过；官方浏览器连接真实 Keycloak 和 TLS，任务编辑、归档/恢复、绑定查询分页通过（10.8 秒）。本地包标记 dirty，仅用于复现和修复验证；干净提交的远程产物仍须重新构建、下载校验和安装复验。
