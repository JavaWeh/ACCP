# D06 / D10 候选版本验收

本轮只生成候选和交接材料，不正式发布、不自动合并、不升级日常环境。四个依赖 PR 为 [运行保障 #12](https://github.com/JavaWeh/ACCP/pull/12)、[协作体验 #13](https://github.com/JavaWeh/ACCP/pull/13)、[Git 来源 #14](https://github.com/JavaWeh/ACCP/pull/14)、[容量与候选交付 #15](https://github.com/JavaWeh/ACCP/pull/15)。

## 功能集验证

- 全量 Linux race 通过，控制面 382.571 秒；事件连续处理、超时后 NAK、延迟重投及工具执行权锁等待的定向 race 23.257 秒通过。
- Go 单元、vet、依赖完整性，Web 类型/构建/格式及浏览器回归通过；交接下载组件覆盖项目诊断与审计导出。
- 契约检查通过：79 个正例、32 个反例、469 处 Schema 编译；工具回归在补入安装包和资源约束校验后共 15 项通过。
- 提交 `f0e3a1e` 的远程文档/契约、控制面、Web、生产基础和候选构建五组 CI 全部通过。新安装、真实 Keycloak 生命周期与 Git 来源正常路径由生产基础 CI 覆盖。
- 依赖扫描包括 Go 可达调用和两个 npm 锁文件；npm 未发现漏洞，Go 无可达漏洞。模块清单中的 OpenPGP 提示不属于应用导入的可达调用，不将模块提示隐藏成“无任何漏洞信息”。完整历史秘密扫描通过，仅保留管理员手册所述精确 SQL 误报排除。

## 恢复与容量

10 万任务恢复、43 表摘要、旧 Session 拒绝、分权重建和空 JetStream 恢复见 [运行保障报告](acceptance-product-operations.md)。实测 RPO 113.488 秒，包含恢复中断和人工操作耗时的完整 RTO 1237.055 秒。
